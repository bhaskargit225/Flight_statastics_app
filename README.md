# Flight_statastics_app

Project Overview

This project demonstrates the design and implementation of an end-to-end data engineering pipeline that ingests publicly available near real-time flight statistics from an external API, processes the data using Apache Spark and Delta Lake, and delivers curated, country-level CSV outputs for downstream consumption.
The solution follows a modern medallion architecture (Bronze → Gold) and emphasizes data quality, schema handling, ACID transactions, and automation readiness.
